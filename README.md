# Brick Sorter 9000

A fast-paced, keyboard-controlled arcade sorting game. Sort 20 bricks in 60 seconds; press **1–4** to route bricks to the matching color bin. Three jams end the run.

## Play

Open `index.html` in a modern desktop browser and press Space or Enter. The game uses canvas graphics and keyboard input; sound starts after interaction.

## Controls

- `1` Red
- `2` Yellow
- `3` Blue
- `4` Green
- `Space` / `Enter` Start or replay

This repository preserves the original game source recovered from the local Devin preview. No gameplay code changes have been made.
